# city

A low-poly city to skate around. Open `index.html` (or the Pages site) on a phone: left
thumb moves, right thumb looks, tap the right pad to jump / ollie, hold it to sprint, the
round key swaps between feet and the board.

`npm install` then `npm run bake` regenerates `models/city.glb` from `LowPoly_City_01.glb`.
